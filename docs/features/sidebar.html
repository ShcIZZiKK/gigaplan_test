Feature: Sidebar ​

Каталог: src/features/sidebar/.

Боковая панель: история чатов, поиск по сообщениям, логин/профиль, popover-действия (rename, delete, logout, close-app, …).

sidebar/
├── store/sidebarStore.ts
├── types/index.ts
├── composables/
│   ├── useSidebarMessageSearch.ts
│   └── useSidebarPopover.ts
├── views/SidebarPanel/
└── components/
    ├── SidebarHeader/, SidebarHistory/, SidebarHistoryItem/
    ├── SidebarSearch/, SidebarSearchInput/
    ├── SidebarLogin/, SidebarUser/, SidebarPopover/

Монтируется из App.vue как <SidebarPanel />.

useSidebarMessageSearch ​

Путь: composables/useSidebarMessageSearch.ts

Модульный singleton (общий debounce и очередь для sidebar- и overlay-инпута).

КонстантаЗначение
SEARCH_DEBOUNCE_MS400

Поток ​

ввод → trim
  ├─ пусто → resetSearchQueue + chatStore.clearSearchQuery
  └─ непусто → debounce 400ms → processSearchQueue
                    ├─ занято → pendingSearchQuery = query
                    └─ свободно → while: searchMessagesByContent → подхват pending

Публичный API ​

МетодПоведение
handleSearchInput(value, source?)source: 'sidebar' | 'overlay' — сейчас не влияет на логику
resetSearchQueue()Сброс pending + таймера (не трогает isSearchQueueProcessing)

Пока API в полёте, промежуточные запросы схлопываются в один pendingSearchQuery (выполняется только последний отличный).

Mobile edit-mode (iPhone) ​

Outside click через document pointerdown (capture):

  1. Delay 50 ms перед bind (не поймать жест открытия).
  2. Игнор, если событие внутри actionsRef (composedPath).
  3. Игнор .gp-sidebar-popover — иначе первый тап по модалке «съедается» edit-mode.

Desktop: Edit / Delete видны сразу. Mobile: Dots → edit → tools.

Закрытие по оверлею ​

Только пара pointerdown.self + click.self на оверлее (защита от ложных закрытий на touch/drag). Диалог: @pointerdown.stop.

close-app ​

ts
emit('close');           // сразу, до leave
settingsStore.closeApp();

Иначе closeApp() спрячет UI до конца анимации, а popover.isOpen останется true → popover всплывёт при следующем открытии.

Edge cases (чеклист) ​

  1. iPhone edit-mode — delay 50 ms, composedPath, ignore .gp-sidebar-popover.
  2. Popover overlay — close только pointerdown + click на self.
  3. close-app — немедленный emit('close') + closeApp().
  4. Rename/delete error — popover остаётся; watch → chat-error.
  5. Favorite limit (5) — hover / 3 с auto-hide на touch.
  6. Favorite group — без заголовка секции.
  7. Клик по активному чату на mobile — только закрыть сайдбар.
  8. send-message — eventBus закрывает сайдбар и search overlay.
  9. Нет defineExpose у Vue-компонентов сайдбара — всё через store/composable.

Feature: Authentication ​

Каталог: src/features/authentication/.

Авторизация по телефону (SMS), upgrade анонимной сессии, имя пользователя, logout / удаление аккаунта.

authentication/
├── store/authStore.ts
├── services/authService.ts
├── types/index.ts
├── composables/useAuthPhone.ts
├── views/AuthenticationView/
└── components/
    ├── AuthenticationForm/
    ├── AuthenticationFormPhone/, AuthenticationFormCode/, AuthenticationFormName/
    ├── AuthenticationTitle/, AuthenticationLogo/, AuthenticationErrors/

Монтируется из App.vue как <AuthenticationView />. Видимость: v-if="getIsOpenPopup".

Cookies ​

КлючСодержимое
gpAccessTokenExpiresAtISO-время истечения access
gpRefreshTokenExpiresAtISO-время истечения refresh

В cookie — даты expiry, не JWT. Сами токены — на стороне HTTP (Set-Cookie бэкенда).

Пишутся в upgradeSession / updateToken; удаляются в logout / deleteAccount. Init стора читает cookies при старте.

Actions — logout / deleteAccount ​

  1. Локально: userName = null, step = 1, телефоны ''.
  2. deleteCookie обеих expiry.
  3. API logout / deleteAccount.
  4. anonymousLogin().
  5. chatStore.clearAllChats().
  6. eventBus.emit('chat:clear-visual').

settingsStore из authStore не вызывается.

Поток 1 → 2 → 3 ​

mermaid
flowchart TB
  open[openPopupAuth] --> step1[Step 1 Phone]
  step1 -->|sendCode OK| step2[Step 2 Code]
  step2 -->|verifyCode + upgradeSession + fetchUserChats| check{userName?}
  check -->|да| close[closePopupAuth]
  check -->|нет| step3[Step 3 Name]
  step3 -->|changeUserName OK| close
После успешного OTP + upgradeДействие
userName уже естьclosePopupAuth() — шаг 3 не показывают
userName пустойincrementStep() → имя → после changeUserName → close

Back: step > 1 → decrementStep(); step === 1 → closePopupAuth().
✕ (только mobile) → settingsStore.closeApp() (весь виджет).

Вся логика через useAuthPhone.

UI: ErrorInput + маска +7 (###) ###-##-## + «Продолжить» + AgreementComponent.

Коды sms_rate_limited / session_sms_limit дублируются: inline authError и fullscreen View.

buttonClickHandler ​

  1. verifyCode(code)
  2. upgradeSession() → cookies + возможно userName
  3. chatStore.fetchUserChats()
  4. userName ? closePopupAuth() : incrementStep()

Повторная отправка ​

  • Таймер durationDisable сек → @finish включает «Отправить код повторно».
  • repeatSendConde → sendCode() → снова таймер.
  • Смена code сбрасывает store error; error → null → timer.restart().

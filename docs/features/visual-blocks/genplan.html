Генплан (genplan) ​

Каталог: src/features/genplan/.

Ключи в dataObjectVisual: genPlan или genplan. visualKey: dark, загрузка sync.

Интерактивный генплан: pan/zoom изображения, бейджи корпусов (клик → сообщение в чат), маркеры текста / 360°, нижний слайдер сдвига, онбординг. Собственного Pinia-store нет.

genplan/
├── types/index.ts
├── composables/useGenplanViewport.ts, useGenplanSlider.ts
├── components/GenplanPointer/, GenplanPreview/
├── views/GenplanView/
└── icons/tour.svg, selector.svg

Поток данных ​

  1. ChatView → GenplanView с v-bind="visualData".
  2. Props: genplan и genPlan (alias); computed: props.genPlan ?? props.genplan.
  3. Remount через contentKey при новом visual.
  4. Watchers в view/composables нет — начальный shift читается при создании viewport.

GenplanView — слои UI ​

  1. Viewport — pan/zoom (touch-action: none, cursor: grab).
  2. Content — translate3d + scale (contentStyle).
  3. Image — render, @load → начальный shift, pointer-events: none.
  4. Badges — elements; @pointerdown.stop; клик → chooseGenplanElement.
  5. Pointers — GenplanPointer → @showWidget.
  6. Slider — thumb синхронен с горизонтальным progress.
  7. Zoom ± — кнопки; :disabled от canZoomIn / canZoomOut.
  8. GenplanPreview — онбординг.
  9. Widget overlay — локальный WidgetView поверх генплана.

onMounted: attachViewport() + attachSlider().

Методы ​

МетодПоведение
chooseGenplanElement(item)chatStore.sendMessage(item.title, { type: item.type, payload: { id: item.estateId } })
showWidget(id)widget = id — локальный overlay, не меняет lastAiAnswer

Клик по корпусу → чат ​

ts
chatStore.sendMessage(item.title, {
  type: item.type,
  payload: { id: item.estateId },
});

Дальше обычный pipeline: thinking → POST message → новый lastAiAnswer.

API ​

Pan / zoom / pinch ​

  • Bounds: maxOffset = max(0, baseSize * scale - viewportSize); offsets в [-max, 0].
  • Wheel: preventDefault → зум к курсору.
  • Interactive зоны (badge, pointer) не стартуют pan.
  • Pinch: scale по отношению дистанций + сдвиг центра; setPointerCapture.

GenplanPreview ​

Онбординг поверх генплана. Текст зависит от settingsStore.getIsMobile. Persistence: sessionStorage ключ genplanPreview. Клик «Понятно» / по оверлею → скрыть на сессию.

Панорама из генплана ​

  1. Pointer type: 'panorama' + uid.
  2. Клик → локальный widget = uid (не смена lastAiAnswer).
  3. Overlay .gp-genplan__widget + <WidgetView :widget="widget" />.
  4. «Назад» → widget = null.

См. также Planoplan widget.

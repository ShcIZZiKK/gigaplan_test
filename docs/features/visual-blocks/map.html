Карта (map) ​

Каталог: src/features/map/.

Ключ в dataObjectVisual: map. visualKey: default, загрузка async.

Интерактивная карта Yandex Maps JS API v3: маркеры с hover-балунами, слайдер контактов, фильтр категорий, круг шаговой доступности (5 / 15 / 25 мин).

map/
├── types/index.ts
├── store/mapStore.ts
├── lib/loadYmapsScript.ts, ymaps3.ts
├── utils/mapCoords.ts, walkingRadius.ts, getCircleGeoJSON.ts
├── views/MapView/
└── components/
    ├── MapBlockComponent/   # YMap, маркеры, радиус, zoom
    ├── MapInfoComponent/    # Swiper contacts
    ├── MapBalloonComponent/ # балуны
    ├── MapFilterComponent/  # фильтры категорий
    └── MapRadiusComponent/  # 5/15/25 мин + toggle

Отдельного services/ / HTTP API нет — данные только из prop map.

Поток данных ​

  1. ChatView при ключе map монтирует MapView с v-bind="visualData".
  2. Prop: map: IMapContent.
  3. onBeforeMount → mapStore.setMap(props.map) (сброс фильтров, фокус на первый маркер).
  4. Remount при смене визуала через contentKey++.
json
{
  "map": {
    "filter": [{ "label": "Школы", "type": "school", "icon": "…", "count": 3 }],
    "location": {
      "zoom": 14,
      "center": [55.75, 37.62],
      "markers": [/* IMapMarker; объект ЖК: modifyClass: "object" */]
    },
    "contacts": [/* IMapContacts с markerId */]
  }
}

Координаты в API: [lat, lng]. На карте — через toYandexCoords → [lng, lat].

Поток фильтров ​

Кто фильтруется: маркеры, чей marker.type есть в map.filter.

Кто всегда виден: маркеры с type, которого нет в map.filter (например объект ЖК).

РежимВидимость фильтруемых
isAllCategoriesActive === trueВсе
иначеТолько activeFilterTypes.includes(marker.type)
toggleFilter из «все» → activeFilterTypes = [type]
выбор всех доступных → снова «все», activeFilterTypes = []
toggleAllFilters off → activeFilterTypes = [] (фильтруемые скрыты)

В UI списка только count > 0. Закрытие панели: крестик / «Показать на карте» / useClickOutside.

Поток радиуса ​

  1. Дефолт: enabled: true, value: 15.
  2. UI (MapRadiusComponent): кнопки RADIUS_OPTIONS = [5, 15, 25] → setRadiusValue; чекбокс → toggleRadius.
  3. Центр круга: getObjectMarker (modifyClass === 'object'). Без него круг не рисуется.
  4. Метры: getWalkingRadiusMeters(value) (~80 м/мин):
МинутыМетры
5400
151200
252000
  1. GeoJSON: getCircleGeoJSON(toYandexCoords(object.coords), meters) (@turf/circle).
  2. Отрисовка: YMapFeature при enabled && objectMarker && geometry; стиль #38ae73, fill opacity 0.2; :key="radius.value" при смене минут.

Компоненты ​

MapView ​

Props: map: IMapContent.
Шаблон: BackgroundSpheres + MapInfoComponent + MapBlockComponent.

MapBlockComponent ​

Всё из стора (props нет). После await ymaps3Ready — Vue-обёртки YMaps.

ПоведениеДетали
staticLocationНачальный { center, zoom } для :location; дальше pan/zoom через API
МаркерыgetVisibleMarkers; click → focus; hover → balloon
РадиусYMapFeature (см. поток выше)
Zoom ±map.setLocation({ zoom ± 1, duration: 300 })
Focus watchmap.setLocation({ center, duration: 500 })
Схемаsaturation: -1

Оверлеи фильтр / радиус / zoom — только после появления staticLocation.

MapInfoComponent ​

Горизонтальный Swiper contacts:

  • клик → focusMarker(contact.markerId); класс is-focused;
  • breakpoints: 1 слайд; с 1280px — 2 при contacts.length > 1;
  • стрелки prev/next если contacts > 1 и не mobile;
  • :touch-start-prevent-default="false" — не блокировать вертикальный скролл родителя на iOS.

MapFilterComponent ​

Кнопка «Фильтр» → панель: «Все категории» + список icon/label/count. Рендер, если filters.length > 0.

MapRadiusComponent ​

Кнопки «N мин» + чекбокс «Радиус шаговой доступности».

MapBalloonComponent ​

Props: balloon, position? → CSS gp-map-balloon_position_${position}.

Связь с чатом ​

Прямых вызовов sendMessage / eventBus нет. Появление и сброс — через pipeline lastAiAnswer / chat:clear-visual.

В ChatMiniInfo тип 'map' есть в typesList (SVG-фон) — клик по miniInfo открывает карту в правой панели.

UX-заметки ​

  • Скролл панели на iPhone: overflow-y: scroll на .gp-map + отключённый touchStartPreventDefault у Swiper контактов.
  • Без маркера modifyClass === 'object' круг не появится даже при enabled: true.

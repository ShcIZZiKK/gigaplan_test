Ход строительства (progress) ​

Каталог: src/features/progress/.

Ключ в dataObjectVisual: progress. visualKey: dark, загрузка sync.

Галерея хода строительства: фильтры (год / месяц / корпус), сетка карточек, полноэкранный альбом фото. Store / HTTP API нет — данные из prop progress.

progress/
├── types/index.ts
├── utils/progressFilters.ts
├── views/ProgressView/
└── components/ProgressFilter/, ProgressCard/, ProgressAlbum/

Правила фильтров (cheat sheet) ​

  1. Год — single-select: один value или ни одного; повторный клик снимает выбор.
  2. Без года — фильтр месяца целиком disabled (opacity: 0.5, pointer-events: none); available months = []; sanitize чистит month.
  3. Смена года (выбор / замена / снятие) → месяцы сбрасываются (resetMonths: true).
  4. Выбранные месяцы не ограничивают доступность годов (явный дизайн).
  5. Корпус скрыт, если пунктов без all ≤ 1.
  6. Недоступные опции — в disabledValues, визуально opacity: 0.5, клик запрещён.
  7. При любом обновлении выбора / данных — sanitizeSelectedFilters отсекает value вне available.

sanitizeSelectedFilters(progress, selected, { resetMonths? }) ​

  1. years — max 1 (.slice(0, 1)).
  2. month = [] если resetMonths, иначе копия; corpus = копия.
  3. Нет года → month = [].
  4. Иначе (не reset) → оставить только месяцы из available.
  5. Отфильтровать years по available years.
  6. Если годов не осталось → снова month = [].
  7. Отфильтровать corpus по available corpus.

Матчинг карточек (filterProgressItems) ​

КатегорияПравило
yearsПустой = любой; иначе item.year ∈ selected
month«Все» (isFilterAllSelected) = любой; иначе item.month ∈ titles выбранных value
corpusПустой = любой; иначе item.corpus.id ∈ selected

Кто кого ограничивает (available) ​

Через getItemsMatchingOtherFilters (текущая категория исключается):

Считаем available дляГодыМесяцыКорпусОсобые правила
years✗✗ всегда✓Месяцы не влияют на годы
month✓✗✓Без выбранного года → []
corpus✓✓✗—

Итого:

  • Год → месяц: без года месяцы недоступны; смена года сбрасывает месяцы.
  • Год ↔ корпус: взаимно сужают available.
  • Месяц → год: не влияет.
  • Месяц ↔ корпус: при выбранном годе взаимно сужают.

Фильтрация карточек применяет все выбранные категории сразу (в отличие от available, где текущая исключается).

ProgressFilter / ProgressCard / ProgressAlbum ​

ProgressFilter ​

Props: filter, modelValue, disabledValues?, multiple? (default true), disabled?.

  • Пункты без all; при > 8 — двухколоночный список (laptop).
  • displayTitle: allTitle если пусто / (multi и выбраны все); иначе titles через ', '.
  • Год или !multiple → toggleYearSelection, иначе toggleMultiSelection.
  • useClickOutside закрывает дропдаун; watch на disabled закрывает открытый.

ProgressCard ​

Бейдж «N фото» (album.length), title, corpus.label, обложка image; клик → emit('open', item).

ProgressAlbum ​

Swiper 1 слайд, speed 500, без loop. Источник: album[].image, fallback — [item.image]. «Назад» → close; prev/next при >1 фото; счётчик N из M фотографий.

Дефолт ​

createDefaultFilterState → все категории [] (= «все» для матчинга карточек).
Для месяцев UI «все» доступен только после выбора года; до этого фильтр disabled и sanitize держит month: [].

Способы покупки (howToBuy) ​

Каталог: src/features/howToBuy/.

Ключ в dataObjectVisual: howToBuy. visualKey: dark, загрузка sync.

Вводный текст о покупке, аккордеон программ, слайдер ипотечных предложений, кнопка консультации → callback-форма чата.

Структура ​

howToBuy/
├── types/index.ts
├── views/HowToBuyView/
└── components/
    ├── HowToBuyProgram/    # аккордеон программы + ипотечный Swiper
    └── HowToBuyMortgage/   # карточка банка

Поток данных ​

  1. ChatView при ключе howToBuy монтирует HowToBuyView с v-bind="visualData".
  2. Prop: howToBuy: IHowToBuyObject.
  3. Remount при смене визуала через contentKey++.
  4. HTTP API у фичи нет; консультация открывает форму через chatStore.

Корень: v-if="howToBuy" → BackgroundSpheres + вводный text + список HowToBuyProgram.

Локального state нет. :key программ — program.id.

HowToBuyProgram ​

Аккордеон одной программы: описание, блок консультации, слайдер ипотек.

Методы ​

Жизненный цикл аккордеона ​

  • watch(isOpen) → measureContentHeight; если открыли — ещё updateSwiperState.
  • onMounted → measure + ResizeObserver (пересчёт только при isOpen).
  • Swiper и навигация рендерятся при program?.mortgage?.length.
  • Prev/next: v-show="canSlidePrev" / canSlideNext.

Кнопка «Заказать консультацию» в блоке consultationText.

HowToBuyMortgage ​

Презентационная карточка банка. State / methods нет.

PropТип
mortgageIHowToBuyMortgage

UI: логотип + название банка; три пропа — ставка / первый взнос / срок; текст условия.

Связь с чатом ​

Единственная прямая связь — chatStore.openCallbackForm() из HowToBuyProgram:

  • ставит callbackFormOpen = true;
  • callbackAnchorMessageId остаётся null (якорь не передаётся).

Дальше форму показывает UI чата (useChatCallbackForm / связанные компоненты). Появление панели howToBuy — через lastAiAnswer; сброс — chat:clear-visual. FullscreenImage не используется.

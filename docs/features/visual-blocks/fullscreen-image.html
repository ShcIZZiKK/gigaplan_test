Fullscreen image (план) ​

Каталог: src/features/fullscreen-image/.

Полноэкранный просмотр изображения (план квартиры и т.п.) с pan/zoom.

Не участвует в switch ключей dataObjectVisual и не выбирает правую панель. Всегда смонтирован рядом с visual-панелью в ChatView. Открывается из ленты через ChatPlan (dataObjectVisual.plan).

Структура ​

fullscreen-image/
├── composables/useImageViewerPanZoom.ts
└── views/FullscreenImage/
    ├── FullscreenImage.vue
    └── FullscreenImage.scss

Поток данных ​

mermaid
sequenceDiagram
  participant Msg as ChatMessage
  participant Plan as ChatPlan
  participant View as ChatView
  participant FS as FullscreenImage
  Msg->>Plan: plan из dataObjectVisual.plan
  Plan->>View: inject openFullscreenImage(plan)
  View->>View: mobile → setActiveView block
  View->>FS: fullScreenImageData = plan
  View->>FS: openImage via expose
  Note over View,FS: setVisualData / chat:clear-visual → closeImage
  1. ChatView.provide('openFullscreenImage', openFullscreenImage).
  2. ChatPlan inject → клик по title / img / иконке fullscreen.
  3. На мобилке: chatStore.setActiveView('block'), затем nextTick → data + openImage().
  4. Сброс: setVisualData (новый visual), событие chat:clear-visual.

Тип payload (в chat/types, не в фиче):

ts
IDataObjectVisualPlan { image: string; title: string }

Пример в сообщении (рядом с другим visual-ключом или без него):

json
{
  "plan": {
    "image": "https://…/floor-plan.png",
    "title": "План квартиры"
  }
}

plan не входит в allRelevantKeys — панель визуала по нему не выбирается.

UI ​

  • кнопка «Назад» → closeImage;
  • viewport + <img draggable="false" @load="handleImageLoad"> с :style="imageTransformStyle";
  • zoom ± (disabled по canZoomIn / canZoomOut).

Жизненный цикл viewport ​

СобытиеПоведение
watch(isOpen) immediateopen → initViewport (attachViewport + rAF handleImageLoad); close → detachViewport
watch(props.image)если открыт и img complete → handleImageLoad (перевписать)

useImageViewerPanZoom ​

Composable: вписывание в viewport, зум к точке (колёсико / кнопки), drag с contain-outside.

Константы ​

КонстантаЗначениеСмысл
MAX_SCALE3Верхняя граница относительно «вписанного» размера
ZOOM_STEP1.25Множитель кнопок ±
WHEEL_SENSITIVITY0.002Множитель к deltaY → Math.exp(…)

Публичный API ​

ExportРоль
imageTransformStyletranslate3d(x, y, 0) scale(s)
canZoomIn / canZoomOutDisabled кнопок (следующий шаг реально меняет scale)
handleImageLoadПосле load — resetView
resetViewscale = 1, measure base, центрирование
zoomIn / zoomOutЗум к центру viewport × ZOOM_STEP
attachViewport / detachViewportwheel, pointer*, ResizeObserver

Модель размеров ​

  1. measureBaseSize — ratio = min(vpW/naturalW, vpH/naturalH) → baseWidth / baseHeight (scale = 1 = «вписано»).
  2. На img проставляются width/height в px по base.
  3. constrainPan: на 100% — центр, если картинка ≤ viewport; при зуме — края как panzoom contain: 'outside'.

Интерактив ​

ЖестПоведение
WheelpreventDefault, зум к курсору (zoomAt)
Pointer LMBcapture + drag; constrainPan на move
Resize viewportпересчёт base с сохранением текущего scale

onBeforeUnmount → detachViewport.

Квартиры / parametric (premises) ​

Каталог: src/features/parametric/.

Ключ в dataObjectVisual: premises. visualKey: dark, загрузка async.

Подборка квартир: сортировка, клиентская пагинация, прогрессивный монтаж карточек, lazy Swiper планировок, клик → сообщение в чат.

parametric/
├── types/index.ts
├── store/parametricStore.ts
├── composables/useCalcHiddenElements.ts
├── views/ParametricView/
└── components/
    ├── ParametricHeader/, ParametricSort/
    ├── ParametricList/, ParametricCard/, ParametricTags/

Иерархия: ParametricView → Header (+ Sort) + List → Card → Tags.

Поток данных ​

  1. Prop: premises: { list: IParametricCard[] }.
  2. onBeforeMount → parametricStore.setPremises(list).
  3. Watch на props нет — обновление через remount (contentKey).

parametricStore (Pinia id: 'parametric') ​

Константа: PARAMETRIC_PREMISES_PAGE_SIZE = 16.

Сортировки (фиксированные) ​

  1. Сначала дешевле (price asc) — default
  2. Сначала дороже (price desc)
  3. Сначала площадь больше (area desc)
  4. Сначала площадь меньше (area asc)

Компоненты ​

ParametricView ​

Props: premises: { list }. Корень: BackgroundSpheres + header + list.

ParametricHeader ​

Счётчик getPremissesResultCount + слот ParametricSort.

ParametricSort ​

Dropdown сортировки из стора. В списке — все варианты кроме текущего. Закрытие: выбор / useClickOutside / toggleShow.

ParametricList ​

  • Карточки из getVisiblePremises, но в DOM — прогрессивно (RENDER_BATCH = 4 за requestAnimationFrame).
  • Кнопка «Показать ещё» → showMorePremises.
  • Цель: не инициализировать десятки Swiper в одном кадре.

ParametricTags ​

Видимые теги + + N в tooltip для скрытых. Раскладка через useCalcHiddenElements. Пока isCalculating — класс calculating, показываются все теги. show_group_title → `${group_title}: ${title}`.

useCalcHiddenElements ​

Путь: composables/useCalcHiddenElements.ts

Какие теги помещаются в ширину ряда, какие уходят в «+ N».

ВходСмысл
itemsИсходные теги
tags / wrapperDOM для измерения
measureCountTagWidth?Async-ширина «+ N»

Алгоритм: набирает слева направо с резервом под счётчик; итерация, пока число скрытых не стабилизируется. ResizeObserver с rAF-батчингом и игнором субпиксельных Δ; полный пересчёт на window.resize и смену items. defaultGap = 8.

Клик → чат ​

ts
chatStore.sendMessage(
  premise.number
    ? `${premise.title} №${premise.number}, ${premise.area} м²`
    : `${premise.title}, ${premise.area} м²`,
  { type: 'premise', payload: { id: premise.id } },
);

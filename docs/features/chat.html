Actions — sendMessage ​

ts
sendMessage(content, selectedOption = null): Promise<boolean>
  1. Защита: isThinking / frozen / пустой trim → выход.
  2. Если режим приложения embed + закрытое app → открываем приложение settingsStore.openApp().
  3. clearHighlightMessage; isThinking = true; eventBus.emit('chat:send-message').
  4. Нет activeChatId → createChat (title = первые 4 слова); lastAiAnswer = gallery.
  5. Создаём USER-сообщение.
  6. Отправляем сообщение на сервер chatService.sendMessage.
  7. Устанавливаем визуальный блок полученного сообщения lastAiAnswer = assistantMessage.dataObjectVisual.
  8. Сортировка → setChatToday.

setupChatAuthInterceptor ​

Путь: api/setupChatAuthInterceptor.ts Регистрация: один раз в useInitApp.

Навешивает обработчик на URL /core/api/v1/chats и 401 ошибку, один раз повторяет попытку отправки:

  1. В случае 401 ошибки, пробует обновить токены authStore.updateToken().
  2. Успех → повторная отправка запроса axios(originalRequest).
  3. Провал → выход и очистка чатов logout() + chatStore.clearAllChats().

ChatList ​

Путь: components/ChatList/ChatList.vue

Лента, infinite scroll, скролл и подсветка из поиска.

Структура шаблона ​

  1. Достигнув верха чата → подргузка сообщений loadOlderMessages
  2. Подгрузка старых сообщений ChatLoading (older)
  3. Вывод сообщений v-for → ChatMessage (+ ChatFormStatus по callbackMessagesNotify)
  4. Ожидание ответа → ChatThinking при thinking
  5. Подргрузка новых сообщений → ChatLoading (newer) + достигнув низа чата
  6. Уведомление об авторизации → ChatNotify при auth-якоре (каждое 5-е ASSISTANT, если не dismiss / не logged in)

revealHighlightedMessage ​

  1. Mobile: закрыть sidebar, activeView = 'chat'.
  2. Дождаться готовности (!loading, видимый list, на mobile — chat).
  3. Найти элемент, scrollListToElement (behavior: 'instant', внутри list).
  4. Включить visualHighlightId + таймер 3 с → clear visual + clearHighlightMessage.
  5. Пока идёт reveal / видна подсветка — не вешать IntersectionObserver.

Повторный reveal при isLoadingChat → false и activeView → chat, если visual ещё нет.

Infinite scroll ​

IntersectionObserver (root = list, rootMargin: 80px). Older → preserveScrollOnPrepend. Observers отключены во время reveal / активной подсветки.

При наличии highlight / visual — не scrollToBottom на смене messages.

ChatAnswer ​

Путь: components/ChatAnswer/ChatAnswer.vue

Prop: visualKey (default | dark) — тема контролов на mobile block.

Показывает последний ASSISTANT-ответ поверх visual-блока (desktop всегда в .gp-chat__blocks, mobile — только в activeView === 'block'), поабзацно с fade.

Константы тайминга ​

КонстантаЗначениеСмысл
PARAGRAPH_MIN_TIMEOUT_MS2500Минимум показа одного абзаца
PARAGRAPH_MAX_TIMEOUT_MS11000Потолок для длинных абзацев
MS_PER_CHARACTER40Оценка «чтения»
PARAGRAPH_TIMEOUT_OFFSET_MS1000Добавка к len * 40
HIDE_DELAY_MS1300Fade-out перед сменой ответа

Таймаут абзаца: clamp(len * 40 + 1000, 2500, 11000) мс.

Поток показа ​

mermaid
flowchart TB
  watch[watch lastAssistantMessageIndex] --> already{уже обработан?}
  already -->|да| skip[skip]
  already -->|нет| body{isBodyActive?}
  body -->|да| pending[pendingMessage + fade-out HIDE_DELAY] --> show
  body -->|нет| show[showAnswer]
  show --> split[split по \\n\\n]
  split --> para[показ абзацев по таймеру]
  para --> last{последний?}
  last -->|нет| next[index++]
  last -->|да| opts[SuggestedOptions + plan]
  1. Watch на индекс последнего ASSISTANT (lastProcessedAssistantMessageIndex защищает от повторного запуска).
  2. Если тело ещё видно — новый ответ кладётся в pendingMessage, текущий fade-out → через HIDE_DELAY_MS вызывается showAnswer.
  3. showAnswer: режет content по \n\n, сбрасывает индекс, включает isBodyActive, пишет suggested options в store.
  4. На каждом абзаце — таймер → следующий; на последнем — showAnswerOptions = true, можно показать ChatPlan.
  5. После полного скрытия текста options остаются на экране.
  6. При открытой callback-форме анимация ответа прячется (callbackFieldsOpen).
  7. Смена / первая загрузка чата — восстановление suggested options последнего ответа без анимации абзацев.

Быстрый старт ​

Требования ​

  • Node.js версии из .nvmrc (24.6)
  • npm

Установка и команды ​

bash
npm install          # установка зависимостей
npm run dev          # локальная разработка (Vite + index.html → main.ts)
npm run build        # сборка проекта, vue-tsc + production IIFE (entry.ts)
npm run preview      # превью сборки
npm run lint         # ESLint + Stylelint
npm run format       # Prettier

Структура репозитория ​

ПутьНазначение
src/Исходный код виджета
public/Статика, gigaplan-autoload.js, тестовые JSON (tests/)
docs/Документация
scripts/Вспомогательные скрипты сборки/окружения
vite.config.tsLib-сборка IIFE, SVG loader, CSS isolation
.gitlab-ci.ymlCI

Режимы разработки данных ​

  • По умолчанию виджет ходит на реальные API (https://gp.ksdev.ru/...).
  • Query-параметр ?fake переключает часть запросов на моки из public/tests/ (см. getIsRealDataSber() в shared/utils/helpers.ts).

Локальный запуск ​

  1. npm run dev
  2. Открыть URL Vite — монтируется через main.ts в режиме button.
  3. Для проверки embed-режима изменить опции в main.ts / вызвать mountGigaplanWidget из собранного бандла.

Сборка виджета ​

Production entry — src/entry.ts:

  • выход: IIFE gigaplan-widget.js (имя зависит от конфига Vite);
  • глобаль: GigaplanWidget;
  • публичный метод: mountGigaplanWidget(options).

Подробнее: Встраивание.

Алиасы TypeScript / Vite ​

  • @ → src/

Пример: import { useChatStore } from '@/features/chat/store/chatStore'.

Обзор документации ​

Виджет ИИ-агента по недвижимости: Vue 3 + Pinia + Vite. Собирается как IIFE-библиотека для встраивания на сайты застройщиков.

Соглашения ​

  • BEM-префикс классов: gp-* (например .gp-chat-list, .gp-button_theme_white).
  • Изоляция CSS: mount в #gigaplan, PostCSS prefixwrap, CSS inject в JS.
  • Стейт: Pinia stores в feature-модулях + settingsStore в shared.
  • События между модулями: eventBus (mitt) — точечно, без жёстких связей.

Shared: стили и токены ​

Каталог: src/assets/styles/.

Главный вход: styles.scss (подключает partials, стили .gigaplan, reset, typography, transitions).

_colors.scss ​

Базовая палитра: $ai, $grey*, $black*, $white*, $error*.

Бренд:

  • $brand-base, $brand-second-base, $brand-third-base — fallback;
  • $brand: var(--gp-brand, $brand-base) — переопределяется с /api/init на mount-элементе.

_breakpoints.scss ​

Диапазоны: mobile → ultra. Часто используемые:

ПеременнаяСмысл
$mobile / $mobile-onlyТелефоны
$tablet-portraitПланшеты и выше
$laptopдесктоп и выше
$laptop-lowerНиже laptop (мобильный layout в JS: 1280px)

В App.vue / settingsStore мобильность = window.innerWidth < 1280.

_font-family.scss / _font-sizes.scss ​

Шрифт: SBSansDisplay.

Миксин font-size($token): h1–h5, lead, p1–p3, caption, button, …

_scale.scss ​

scss
@include scale.scale(padding, 16, 24, 40);

Задаёт значения для mobile / tablet / laptop (px → адаптив на больших экранах).

_mixins.scss ​

МиксинНазначение
transition / transition-customАнимации свойств
reset-buttonСброс стилей <button>
rounded($side, XS|S|M|L|XL|XXL)Радиусы
hide-scrollbar / custom-scrollbarСкроллбары
visually-hiddenскрытие элемента

_vertical-indent.scss ​

Именованные уровни отступов (rose, tomato, yellow, orange, …):

scss
@include vertical-indent.margin-level(top, yellow);
@include vertical-indent.padding-level(all, orange);

_grid-mixins.scss ​

Сетка на 36 колонок: row, column, push/post, vertical paddings/margins.

_management-layers.scss ​

Z-index через z($layer):

hide, zero, default, nav, header, thinking, sidebar, popup, tooltip, map-filter, total (99999) для button-режима.

Изоляция на хосте ​

В vite.config.ts PostCSS prefixwrap оборачивает стили селектором #gigaplan.gigaplan (кроме blacklist), чтобы виджет не ломал CSS сайта заказчика.

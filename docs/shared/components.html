Shared: компоненты ​

Каталог: src/shared/components/.

Общие правила:

  • префикс классов gp-*;
  • многие принимают prop modify (строка или массив доп. CSS-классов);
  • клик у кнопок — нативный @click на корне, отдельного emit обычно нет.

Expose (методы) ​

МетодСигнатураОписание

Lifecycle (внутреннее) ​

  1. loadCaptchaScript → inject captcha.js.
  2. initializeCaptcha → smartCaptcha.render + subscribe.
  3. Unmount → destroy, passExecuteMethod(null), удаление script если последний инстанс.

Где используется: ChatAction (callback-форма).

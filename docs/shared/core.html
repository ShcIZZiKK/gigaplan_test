hexToRgb(hex: string): string ​

Конвертирует HEX-цвет #RRGGBB в строку rgb(r, g, b).

  • Берёт срезы hex.slice(1, 3), (3, 5), (5, 7) и парсит как base-16.
  • Ожидает формат с # и ровно 6 hex-цифр (короткий #RGB не поддерживается).
  • Сейчас в коде проекта не вызывается (утилита на будущее / legacy).

throttle<T>(func: T, ms: number) ​

Ограничивает частоту вызовов: не чаще одного раза за ms мс.

  • Первый вызов в окне выполняется сразу.
  • Пока идёт «кульдаун», аргументы последнего вызова сохраняются (savedArgs / savedThis).
  • По истечении ms wrapper вызывается ещё раз с сохранёнными аргументами (trailing call).
  • Возвращает обёртку с той же сигнатурой Parameters / ReturnType.
  • Сейчас в коде проекта не вызывается.

debounce(fun, time): (args) => any ​

Откладывает вызов, пока поток вызовов не «затихнет» на time мс.

  • Каждый новый вызов в пределах time сбрасывает предыдущий setTimeout.
  • После паузы вызывается fun(args) один раз с последними аргументами.
  • В отличие от throttle, не выполняет функцию на первом вызове сразу.
  • Сейчас в коде проекта не вызывается.

blobToBase64(blob: Blob): Promise<string> ​

Читает Blob через FileReader.readAsDataURL.

  • Resolve: data-URL вида data:<mime>;base64,….
  • Reject при reader.onerror.
  • Сейчас в коде проекта не вызывается напрямую.

encodeWAV(samples: Float32Array, sampleRate: number): ArrayBuffer ​

Собирает PCM WAV (mono, 16-bit) из сэмплов.

  1. Аллоцирует ArrayBuffer = 44 байта заголовка + samples.length * 2.
  2. Пишет RIFF/WAVE/fmt (PCM, 1 канал, sampleRate, 16 bit).
  3. Клипует каждый float в [-1, 1] и пишет как Int16 little-endian.
  4. Возвращает сырой ArrayBuffer (не Blob).

Используется внутри webmToWav.

webmToWav(blob: Blob): Promise<Blob> ​

Конвертирует записанный WebM/Opus (или другой decoded blob) в audio/wav.

  1. blob.arrayBuffer() → AudioContext.decodeAudioData.
  2. Берёт первый канал (getChannelData(0)) и sampleRate.
  3. encodeWAV → new Blob([wavBuffer], { type: 'audio/wav' }).

Где: useAudioRecording — fallback MediaRecorder → WAV перед chatStore.transcribeAudioMessage.

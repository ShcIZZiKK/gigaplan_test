Архитектура ​

Назначение ​

Gigaplan Frontend — встраиваемый виджет чата с ИИ-агентом для жилых комплексов. Пользователь общается в чате; ответы ассистента могут содержать визуальные блоки (карта, генплан, квартиры, документы и т.д.), которые открываются в соседней панели.

Feature-модули ​

Каждая папка в src/features/<name>/ обычно содержит:

  • views/ — экран, монтируемый из App или ChatView;
  • components/ — части экрана;
  • store/ — Pinia (если нужен локальный стейт);
  • types/ — TypeScript-контракты;
  • опционально services/, composables/, icons/, utils/, api/.

Shared ​

Переиспользуемый UI-kit, settingsStore, сервисы init-проекта, утилиты, иконки. Features не должны дублировать базовые кнопки/инпуты — берут из shared/components.

Потоки данных ​

Инициализация ​

  1. useInitApp → сначала задаёт axios baseURL и credentials. Если задан Query-параметр ?fake, то baseURL '', иначе указанный домен.
  2. settingsStore.setMode → устанавливает режим отображения всего приложения button|embed кнопкой или встраиваемым блоком.
  3. settingsStore.getBaseDataProject → получает брендовые цвета, стартовое сообщение, базовую галерею, frozen (заморожен ли проект). Если ответ возвращается 404 статус, то всё приложение скрывается и дальнейшие запросы не отправляются.
  4. Auth → запрос данных пользователя, обновление токена через рефреш-токен или анонимная авторизация.
  5. chatStore.fetchUserChats() → запрос чатов пользователя.

Сообщение пользователя ​

  1. ChatAction / EmptyChat / SuggestedOptions → chatStore.sendMessage.
  2. Thinking-состояние → ответ ассистента в activeChat.messages.
  3. При наличии dataObjectVisual → lastAiAnswer → ChatView монтирует visual-компонент.

Поиск по сообщениям ​

  1. Сайдбар → searchMessagesByContent.
  2. Клик по результату → openChatAtMessage.
  3. highlightMessageId в сторе + ChatList скроллит и включает локальную визуальную подсветку на 3 с.

Подробности: Chat.

Паттерны ​

Pinia ​

  • Имена getters: get*.
  • Actions вызывают services и мутируют state.
  • Feature-store не должен знать о DOM; UI-эффекты (скролл, класс подсветки) — в компонентах.

Event bus ​

shared/utils/eventBus.ts (mitt):

  • chat:send-message — событие при отправке сообщения (закрытие сайдбара/поиска);
  • chat:clear-visual — сброс visual-панели при logout и т.п.

Именование CSS (BEM) ​

  • Блок: .gp-chat-list
  • Элемент: .gp-chat-list__sentinel
  • Модификатор темы: .gp-button_theme_white
  • Состояние: .is-open, .is-highlighted

Prop modify у shared-компонентов добавляет внешние классы без ломки базовых стилей.

Изоляция на хост-странице ​

  • Корень #gigaplan / .gigaplan
  • PostCSS prefixwrap в Vite
  • CSS инжектится в JS-бандл
  • В режиме button — высокий z-index (total) чтобы перекрывать другие библиотеки/блоки, а также lock scroll body хоста

Связь ChatView и визуалов ​

ChatView смотрит на chatStore.getLastAiAnswer (dataObjectVisual) и выбирает компонент по ключу (map, premises, images, …). Таблица ключей — в Визуальных блоках.
